
# SECURETEXT
## Aplikasi Keamanan Sistem

### Deskripsi
SECURETEXT adalah aplikasi keamanan pesan
berbasis Python yang digunakan untuk melakukan
enkripsi dan dekripsi pesan menggunakan algoritma
AES-256-GCM.

### Tujuan
1. Melindungi kerahasiaan pesan.
2. Memahami proses enkripsi dan dekripsi.
3. Menerapkan algoritma kriptografi.
4. Menguji keamanan data menggunakan password.

### Teknologi
- Python
- AES-256-GCM
- Scrypt
- Library Cryptography

### Fitur
1. Enkripsi pesan.
2. Dekripsi pesan.
3. Penggunaan password sebagai kunci.
4. Validasi password.
5. Pemeriksaan integritas ciphertext.

### Cara Menjalankan
1. Instal Python.
2. Instal library cryptography.
3. Buka terminal pada folder proyek.
4. Jalankan perintah:

   python main.py
